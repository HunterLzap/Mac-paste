MacPaste UI Redesign Proposal · v2.0 概念交互稿

把剪贴板、截图、贴图融为一体化的原生 macOS 浅色工具集

目前 MacPaste 的核心功能已经非常强（按序粘贴、表格区域框选、原地翻译、滚动长截图、可交互活贴图）， 下一轮 UI 迭代建议聚焦在视觉语言统一、卡片信息层级降噪、快捷键与状态可感知性提升，让所有浮窗和面板看起来像同一套原生设计系统。

1. 统一浅色层级（3 层材质）

底栏使用微透浅灰毛玻璃（#F7F8FB），条目使用纯白高光卡片（#FFFFFF）+ 极细描边，浮层菜单带柔和投影，彻底消除各模块色温割裂。

2. 卡片信息密度重构

剪贴板条目将「来源应用图标 / 类型徽标 / 相对时间」归整为轻量化底行；常驻操作收起，悬停浮现毛玻璃小工具条，视觉更透气。

3. 渐进式高级能力引导

长文本「按序粘贴」、表格「区域框选」、截图「原地翻译」提供直观状态胶囊与键盘徽章提示（⌘V / F1 / F3），不用记就能用。

4. 微交互与统一动效

选中卡片轻蓝高亮、复制/粘贴成功瞬间绿闪微反馈、贴图折叠胶囊与透明度滑块统一为紧凑胶囊控件。

六、推荐迭代落地路线（低风险分 3 步推进）

不破坏现有 SwiftUI / AppKit 混合架构，可按阶段平滑升级

Phase 1 · 设计系统抽离

建立统一 `AppTheme` Token 层

  • 把颜色、圆角、阴影、字体层级统一抽到 AppTheme.swift，让 SwiftUI 与 AppKit 共用同一套浅色语义 Token。
  • 为 `NSColor` 与 SwiftUI `Color` 提供一致的 surface / card / hairline / accent。
Phase 2 · 剪贴板与设置精修

卡片质感升级 & 信息降噪

  • 升级 `ItemRowView`、`TableCardView`、`ImageCell` 为纯白圆角卡片 + 极细描边，悬停浮现轻量化操作胶囊。
  • 重构 `SettingsView` 为分组白底卡片，快捷键改用 Keycap 键帽排版。
Phase 3 · 贴图与截图细节打磨

微动效与视觉收口

  • 将 `ScreenshotOverlayView` 的图标绘制全部统一为矢量居中渲染，加入更细腻的阴影层次与交互高亮。
  • 优化 `PinContentView` 顶部工具胶囊与双语对照卡片间距，统一圆角与分割线。
